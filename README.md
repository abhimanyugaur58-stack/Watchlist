# वॉच-लिस्ट

अभिमन्यु का अपना Android ऐप: कौन-सी सीरीज़ अभी चल रही है, आगे क्या देखना है, कितने एपिसोड बाकी हैं, और जो देख लीं उनकी डायरी।

## यह रिपॉज़िटरी किसलिए है

- **`docs/`**: ऐप का असली पेज (`app.html`) और उसका संस्करण नंबर (`version.json`)। GitHub Pages इन्हें इंटरनेट पर रखता है, और फ़ोन या टैब पर लगा ऐप खुलते ही यहाँ से नया संस्करण ले लेता है। इसलिए नए फ़ीचर के लिए ऐप दोबारा इंस्टॉल नहीं करना पड़ता।
- **`android/`**: Android ऐप का ढाँचा। इसे सिर्फ़ तभी बदलना पड़ता है जब कोई नई परमिशन या आइकन जैसी चीज़ चाहिए।
- **`tools/build.sh`**: ढाँचे से नई APK फ़ाइल बनाने का तरीका।
- **`tests/`**: हर अपडेट से पहले चलने वाली जाँचें।

## आपका डेटा

आपकी टिक, अंक, किरदार और नोट्स सिर्फ़ आपके फ़ोन या टैब में रहते हैं। वे इस रिपॉज़िटरी में या इंटरनेट पर कहीं नहीं जाते। यह रिपॉज़िटरी Public है, इसलिए इसमें कभी कोई निजी जानकारी नहीं रखी जाती।
